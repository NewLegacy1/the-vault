## Slide / lesson notes

If you're spending above $500 per day, you can ignore this
If you are not, the minimum daily spend is WHATEVER you're comfortable spending per day, no matter WHAT.

Ideally, we recommend a minimum of $50-$100 per day

You can be less, you can be more, but $100 per day is always a great place to start to give the machine data. 
Just make sure you have the budget to test for 1-2+ months.
