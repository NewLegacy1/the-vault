### Feedback Loops // Growth Loops

A feedback loop is a process where the output of a system is used as input to modify or reinforce future actions within that same system
"Insanity is doing the same thing over and over again and expecting different results."
- Albert Einstein
The more you complete feedback loops, the faster you grow
