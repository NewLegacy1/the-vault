# The Loop

The whole program compresses to:

**Study → Research → Create → Test → Feedback Loop → Repeat**

- Test in **1 campaign**. Spend = signal. No spend = not it.
- Feedback loop = educated guess *why* it worked or didn’t, then research or iterate.
- Spend most time **outside Ads Manager** (ads, offers, learnings).
