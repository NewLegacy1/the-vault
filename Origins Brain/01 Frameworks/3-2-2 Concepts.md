# 3-2-2 Concepts

**3:2:2** = 3 creatives, 2 bodies, 2 headlines = one **concept**.

- **Concept** = what you’re testing (iteration, format, avatar, angle).
- **Angle** = reason to buy. Every ad needs an angle.
- **Format** = delivery (UGC, static, VO + B-roll, slideshow). Format ≠ angle.

## Testing methods

- **Marksman:** 3 angles, 1 execution each — good for images.
- **Sniper:** 1 angle, 3 executions — good for video / doubling down.
- **Shotgun:** spray. Don’t.

Plan **5–10 first concepts**. Mark Done only after [[Learnings Loop|learnings]] are written.

Copy is the last 10–20% that separates winners. Execution is a top reason ads fail.
