# CBO Testing

- **1 broad CBO.** One concept per ad set. Images and video OK in the same campaign, separate ad sets.
- Champions ad set for proven winners (empty if none).
- Test **3–7 days**. Kill at **ad-set** level, not ad level.
- Winner = majority of spend at KPI **or** campaign ROAS improved.
- Target ROAS ≈ **breakeven + 1**.
- Scale **~20%** when at target; scale down ~20% if you overshot.
- Suggested test fuel: **$50–$100/day** if you can sustain 1–2 months.
- Ignore CTR/CPC vanity. Care about **spend + ROAS**.
- Bad ads getting spend = Meta exploring. Zoom out; don’t panic-kill.
