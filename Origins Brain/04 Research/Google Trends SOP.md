# Google Trends SOP

Automate later. Until then, for every candidate:

1. Query the **desire language**, not only the SKU ("snoring", not only "anti snore ring").
2. Screenshot **5-year** and **12-month** (US first, then ship-to countries).
3. Capture **related queries** and **rising queries**.
4. Pass if 12m is stable or rising **and** 5y isn't a single spike. Fail a one-week rocket with no base.
5. Drop images/links into the candidate note.
